# 🚨 Women Crime Data Analysis (India)

## 📌 Project Overview
This project analyzes crime data related to women in India using Python. The goal is to identify trends, patterns, and high-risk regions using exploratory data analysis and interactive visualizations.

## 🎯 Objectives
- Analyze crime trends over years
- Identify high-risk states and districts
- Study distribution of different crime categories
- Perform data cleaning and preprocessing
- Build interactive dashboards

## 🛠️ Tools & Technologies
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Plotly (Interactive Visualizations)
- Jupyter Notebook

## 📊 Key Insights
- Crime is highly concentrated in a few states like Uttar Pradesh and Maharashtra
- Majority of regions fall under high crime severity
- Crime trends show fluctuations but an overall increasing pattern
- Certain districts act as major crime hotspots

## 📈 Interactive Features
- Dropdown-based state analysis
- Year-wise filtering
- Crime type exploration dashboards

## 📁 Dataset
- Source: Government crime dataset (India)
- Features include state, district, crime categories, and year-wise data
